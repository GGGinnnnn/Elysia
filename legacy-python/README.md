# 旧版：Python / PyQt6 实现（已归档）

这里是爱莉希雅桌宠的**第一版实现**，用 Python 3 + PyQt6 编写，保留存档不再继续维护。

## 运行方式

```bash
pip install PyQt6 requests
python Elysia.py
```

需要把 `assets/` 目录（8 个 GIF 表情）和 `icon.ico` 放在同级目录下。
`assets/` 已从仓库移除，可从新版的 `src/ElysiaPet/Assets/` 直接复制过来。

## 为什么重写

Python 版本功能是完整的，但遇到几类难以根治的问题：

- 单个文件 1600 余行，界面、业务逻辑、系统调用全部混在一起；
- 每个网络请求都新建一个 `QThread`，没有取消机制，连发消息会互相干扰；
- 裸 `except Exception` / `except: pass` 吞掉异常，打包成 exe 后出问题完全查不到原因；
- 用 `int()` 直接转换用户输入，填了汉字就抛异常且静默失败；
- `json.dump` 直接覆盖配置文件，写到一半崩溃就全部丢失；
- `requests.post(..., verify=False)` 关闭了证书校验。

新版 `ElysiaPet` 用 C# / .NET 10 / WPF 重写，逐条解决了上述问题，
并把发布方式改成了零依赖的单文件 exe。详细对照见仓库根目录的 `README.md` 与 `PROGRESS.md`。

### 🌸 爱莉希雅桌面看板娘 & 智能管家 (DesktopPet) ♪

集 **智能对话、高效率生产力工具、日程管家、全能看板娘** 于一体的桌面助手。

- **快捷对话框**：鼠标左键点击桌宠唤醒 / 隐藏底部输入框，10 秒无操作自动缩回
- **自由等比例缩放**：右键按住左右拖动，桌宠、气泡、输入框与字体同步缩放
- **智能对话与情绪联动**：接入大模型，按语境切换 8 种 GIF 表情
- **整点报时**：每个时段可配置多句语录，触发时随机抽取
- **声控日程**：直接说「12:00提醒我吃饭」即可录入，到点气泡 + 系统弹窗双重提醒
- **斜杠快捷指令**：`/终端`、`/任务管理器`、`/计算器` 等秒开 Windows 系统工具
- **右键菜单自定义快捷启动**：绑定常用软件，实时出现在桌宠右键菜单顶部

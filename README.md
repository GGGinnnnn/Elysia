## 🌟 核心功能一览

### 🌸 1. 视觉与丝滑交互
* **快捷对话框：** 鼠标左键点击桌宠，即可唤醒或隐藏底部居中的精致输入框。
* **智能隐形：** 输入框展开后若 10 秒内无操作，会自动静默缩回，绝不占用宝贵的屏幕空间。
* **自由等比例缩放：** 右键按住桌宠身体并横向拖动，桌宠、聊天气泡、输入框及字体都会**完美等比例同步放大或缩小**！
* **物理像素级排版：** 采用物理坐标排版引擎，确保气泡、身体、输入框界限分明，**彻底杜绝组件重叠挡脸的缺陷**。

### 💬 2. 智能对话与情绪联动
* **完美人设沉浸：** 深度适配爱莉希雅人设风格，语气欢快、自然，拒绝生硬的机械式回答。
* **丰富动态表情：** 根据聊天语境，实时无缝切换眨眼、开心、思考、哭泣、疑问、傲娇等 8 种精美动图状态。
* **对谈历史管理：** 独立的控制台可查阅完整聊天历史，在列表上**点击右键即可精准删除单条记录**。

### ⏰ 3. 专属时钟与智能日程管家
* **爱莉希雅式整点报时：** 支持全局整点报时开关。每个时段可配置多句精美语录，**触发时随机抽取**，充满新鲜感。
* **声控智能日程记录：** 直接在聊天框对她说 *“12:00提醒我吃饭”* 或 *“15:30提醒我开会”*，系统将自动利用正则表达式智能解析并记录。
* **强力双重提醒：** 设定时间一到，桌宠不仅会冒出气泡提示，更会**在屏幕中央弹出系统强提醒对话框**，双重保险！

### 🚀 4. 生产力快捷指令
在快捷输入框中输入 **“斜杠 / + 中文关键词”** 并回车，即可像魔法一样秒开常用的 Windows 系统工具：
* `/终端` 或 `/命令行` ➔ 唤醒黑色命令行窗口 (CMD)
* `/任务管理器` ➔ 快捷查看或强制结束卡死进程
* `/设备管理器` ➔ 快速查看电脑硬件与驱动
* `/服务` ➔ 一键直达 Windows 本地服务设置
* `/控制面板` ➔ 开启传统系统设置中心
* `/计算器` ➔ 弹出系统自带计算器
* `/记事本` ➔ 秒开临时草稿本
* `/网卡设置` ➔ 快速查看或修复网络连接

### 💻 5. 右键菜单自定义快捷启动
* **动态菜单依赖注入：** 在后台管理页面中，自由添加常用软件名称（如：*Steam、网易云、浏览器*）并选取其 `.exe` 路径。
* **一键秒开：** 设置完成后，**桌宠的右键菜单顶部会实时吐出对应的快捷启动选项**，看板娘属性直接拉满！

# Elysia
<h3>💡 基础操作</h3>
<p><b>左键点击：</b> 唤醒/隐藏底部的快捷聊天输入框。</p>
<p><b>左键按住拖拽：</b> 可以在桌面上任意移动桌宠的位置。</p>
<p><b>右键按住横向拖拽：</b> 自由等比例放大或缩小桌宠、气泡和输入框。</p>
<p><b>右键点击：</b> 呼出主菜单，可直接跳转到后台各控制面板。</p>
<br>
<h3>💬 智能对话与联动</h3>
<p>1. 在快捷输入框或此管理后台中发送消息，桌宠都会根据语境做出对应的<b>表情动作</b>（wink、哭泣、疑问等）。</p>
<p>2. 点击气泡或在气泡打字时，系统会自动重置隐藏倒计时。</p>
<br>
<h3>⚙️ 后台管理</h3>
<p>1. <b>历史对话：</b> 右键点击左侧列表的“对谈记录”可以彻底删除单条历史。</p>
<p>2. <b>设置中心：</b> 支持修改 API Key、角色拟人化预设、主人昵称以及待机提示触发时间。</p>
